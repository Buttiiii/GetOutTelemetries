# VisionWhite Cursor Assets

Optional cursor files go in this folder if you own them or have redistribution rights.

Required files:

- `pointer.cur`
- `help.cur`
- `work.ani`
- `busy.ani`
- `text.cur`
- `link.cur`

The repository does not include third-party cursor assets. If files are missing, cursor setup is skipped cleanly and logged.
